# Identity Cloud – QR-Based Student Identity Verification System

A full-stack identity verification platform deeply integrated with **Card Studio**.  
Students are created in Card Studio → QR codes link to Identity Cloud → Scan opens a live verification page.

---

## 📁 Project Structure

```
identity-cloud/
├── backend/             ← Identity Cloud API (Node.js + LokiJS)  [port 4000]
├── frontend/            ← Identity Cloud UI (Vue 3 + Vite)        [port 5174]
├── card-studio/         ← Modified Card Studio (backend + frontend)
│   ├── backend/         ← Card Studio API                         [port 5000]
│   └── frontend/        ← Card Studio UI (Vue 3 + Vite)           [port 5173]
└── README.md
```

## 🔄 System Flow

```
Card Studio                    Identity Cloud
──────────────────────────     ─────────────────────────────
1. Create students             ← Students stored in LokiJS
2. QR auto-generated           ← URL: http://localhost:5174/{slug}/{id}
3. 🚀 Publish to Identity Cloud → POST /api/publish (port 4000)
                                   ↓ Upserts students in LokiJS
QR code is scanned             → GET /api/verify/{slug}/{id}
                                   ↓ Increments scanCount
                               → Beautiful identity card shown
```

## 🔌 API Reference

### Identity Cloud Backend (port 4000)

| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/api/publish` | Receive and store students from Card Studio |
| `GET`  | `/api/verify/:schoolSlug/:studentId` | Verify identity, increment scan count |
| `GET`  | `/api/school/:slug` | Get school info + student count |
| `GET`  | `/api/school/:slug/students` | List all students for a school |
| `GET`  | `/api/stats` | Aggregate stats (schools, students, active) |
| `GET`  | `/api/health` | Health check |

### POST /api/publish — Payload

```json
{
  "schoolName": "Green Hills Academy",
  "schoolSlug": "green-hills",
  "themeColor": "#00e5a0",
  "logo": "http://...",
  "students": [
    {
      "studentId": "STU-00012",
      "fullName": "Alice Munroe",
      "photoUrl": "http://localhost:5000/uploads/photos/...",
      "class": "Grade 10A",
      "issuedAt": "2025-01-01T00:00:00.000Z",
      "expiresAt": "2026-01-01T00:00:00.000Z"
    }
  ]
}
```

### GET /api/verify/:schoolSlug/:studentId — Response

```json
{
  "student": {
    "studentId": "STU-00012",
    "fullName": "Alice Munroe",
    "photoUrl": "http://...",
    "schoolSlug": "green-hills",
    "class": "Grade 10A",
    "status": "active",
    "issuedAt": "2025-01-01T00:00:00.000Z",
    "expiresAt": "2026-01-01T00:00:00.000Z",
    "scanCount": 7,
    "lastScannedAt": "2026-04-28T10:30:00.000Z",

  },
  "school": {
    "name": "Green Hills Academy",
    "slug": "green-hills",
    "themeColor": "#00e5a0",

  }
}
```

## 🗄️ Database Schema (LokiJS)

### Students Collection

```js
{
  _id,           // UUID
  studentId,     // e.g. "STU-00012"
  fullName,      // e.g. "Alice Munroe"
  photoUrl,      // absolute URL or null
  schoolSlug,    // e.g. "green-hills"
  class,         // e.g. "Grade 10A"
  status,        // "active" | "expired" | "revoked"
  issuedAt,      // ISO date string
  expiresAt,     // ISO date string or null
  scanCount,     // integer, incremented on each verify
  lastScannedAt, // ISO date string or null
  createdAt,     // ISO date string
  updatedAt,     // ISO date string
}
```

### Schools Collection

```js
{
  _id,        // UUID
  name,       // "Green Hills Academy"
  slug,       // "green-hills"  ← unique key
  themeColor, // "#00e5a0"
  logo,       // URL or null
  createdAt,
  updatedAt,
}
```

## 🔗 QR Code URL Format

QR codes generated by Card Studio encode:

```
http://localhost:5174/{schoolSlug}/{studentId}
```

Example:
```
http://localhost:5174/green-hills/STU-00012
```

Rules:
- `schoolSlug` → lowercase, hyphenated: `Green Hills Academy` → `green-hills`
- `studentId` → URL-encoded if it contains special chars

## 🚀 Publish from Card Studio

1. Open **Card Studio** → **Settings**
2. Click **🚀 Publish Cards**
3. Configure school name, scope, and field toggles
4. Click **Publish Cards**

Card Studio's backend (`/api/publish`) forwards the payload to Identity Cloud's `POST /api/publish`.

## 🌐 Verification Page

When a QR is scanned, the user sees a glassmorphism identity card with:

- 📸 Student photo (or initials avatar)
- 👤 Full name + school name
- 🟢 Live status badge (Active / Expired / Revoked)
- 📅 Issue date, expiry date, remaining days
- 🔢 Scan count + last scanned time
- ✅ "Verified by Identity Cloud" badge

## 🔒 Status Logic

| Condition | Status |
|-----------|--------|
| `expiresAt` is in the future | `active` |
| `expiresAt` is in the past | `expired` (auto-updated on scan) |
| Manually set | `revoked` |

Status is recalculated on every `/api/verify` call so it stays current.
